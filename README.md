# WhatsApp Bot 9-V Class

Бот расписания и полезных инструментов для 9-В класса (№104 ЖББ мектеби).

## Установка и запуск

1. Установить зависимости (нужен Node.js 18+):
   ```bash
   npm install
   ```
2. Скопировать `.env.example` в `.env` и заполнить:
   - `DATABASE_URL` — строка подключения Neon Postgres
   - `PAIR_PHONE` — номер бота
   - `ANTHROPIC_API_KEY` — для команды `/ai` (необязательно)
3. Запустить:
   ```bash
   npm start
   ```
4. При первом запуске в консоли появится `КОД ПРИВЯЗКИ` — введите его в WhatsApp:
   Связанные устройства → Привязать устройство → Привязать по номеру телефона.

## Возможности

- `/понедельник` … `/пятница`, `/расписание` — расписание
- `/люди` — список класса, `/grr [имя]` — поздравление с днём рождения
- Автопоздравления с днём рождения в 06:00 по Кыргызстану во всех группах бота
- RP: ответом на сообщение написать `обнять`, `поцеловать`, `ударить`, `погладить`, `пнуть`, `успокоить`, `слить`
  (имя определяется по номеру из таблицы в `src/rp.js`)
- `/ai [вопрос]`, `/banana`, `/news`, `/palc`, `/baran`, `/помощь`
