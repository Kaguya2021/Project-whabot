# Kaguya 2.0 — WhatsApp Group Bot (9-В класс)

Активный групповой WhatsApp-бот для 9-В класса (№104 ЖББ мектеби) с быстрым **Google Gemini AI**, умным расписанием, рейтингами активности, дуэлями, отношениями и RP.

## Установка и запуск

1. Установите зависимости (нужен Node.js 18+):
   ```bash
   npm install
   ```
2. Скопируйте `.env.example` в `.env` (или добавьте переменные на Render / Railway):
   - `DATABASE_URL` — строка подключения PostgreSQL (Neon и т.п.)
   - `PAIR_PHONE` — номер WhatsApp для привязки бота
   - `GEMINI_API_KEY` — ключ Google Gemini API (получить бесплатно или с кредитами Google AI Pro в [Google AI Studio](https://aistudio.google.com/apikey))
   - `GEMINI_MODEL` — модель Gemini (по умолчанию `gemini-3.5-flash-lite`, также можно `gemini-3.6-flash` или `gemini-flash-latest`)
3. Запустите:
   ```bash
   npm start
   ```
4. При первом запуске в консоли появится `КОД ПРИВЯЗКИ` — введите его в WhatsApp:
   **Связанные устройства → Привязать устройство → Привязать по номеру телефона**.

## Возможности

- **Gemini AI** (сразу чёткий ответ без сообщения «Анализирую...», память диалога, понимание цитируемого сообщения):
  - `/ai [вопрос]` или `кагуя [вопрос]` — спросить ИИ
  - Ответ (reply) на сообщение бота — продолжить диалог
  - `/сброс` — очистить память диалога
- **Школа и расписание**:
  - `/сегодня`, `/завтра`, `/урок` (показывает текущий урок/перемену и минуты до звонка)
  - `/понедельник` … `/пятница`, `/расписание`
  - `/люди`, `/dr`, `/скородр` (3 ближайших ДР), `/grr [имя]`
  - Автопоздравления с днём рождения в 06:00 (UTC+6)
- **Актив группы**:
  - `/топ` — топ-10 самых активных участников (сообщения, уровень, XP)
  - `/стата` — личная карточка с рангом, XP и счётом дуэлей
  - `/дуэль` (ответом на сообщение) — быстрая битва 1 на 1
  - `/все [текст]` — упоминание всех участников группы
  - Автоприветствие новых участников группы
- **Игры, отношения и RP**:
  - `/кто [вопрос]`, `/инфа [утверждение]`, `/шар [вопрос]`, `/выбери [А] или [Б]`, `/шип [А + Б]`, `/цитата`
  - `/banana`, `/news`, `/palc`, `/baran`
  - `/rp` — список всех RP-действий
  - `/пара`, `/пары`, `/пол м|ж`, `/расстаться` + `подружиться` / `встречаться` / `пожениться`
